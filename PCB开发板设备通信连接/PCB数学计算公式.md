## 电路、布局、布线联合约束优化公式”**：先要求连接正确、电路功能达标、满足制造条件，再从合格方案中选择线长、损耗和成本更优的方案。

## 1. 总公式

[I] 用 \(X\) 表示一个完整的候选设计，建立：

\[
\boxed{
X^{*}\in
\underset{X\in\mathcal F}{\operatorname{arg\,min}}
\left[
\alpha\frac{L_{\mathrm{total}}(X)}{L_0}
+\beta\frac{N_{\mathrm{via}}(X)}{N_0}
+\gamma\frac{P_{\mathrm{loss}}(X)}{P_0}
+\delta\frac{C_{\mathrm{total}}(X)}{C_0}
\right]
}
\]

[I] 各符号在这个模型中的定义如下：

| 符号 | 定义 |
|---|---|
| \(X\) | 元件型号及参数、位置、旋转角度、安装面、铜线和铜面的形状、所在层、线宽及过孔位置 |
| \(\mathcal F\) | **满足全部硬性要求的设计集合**，具体条件见下一节 |
| \(L_{\mathrm{total}}\) | 整板实际布线总长度，同网共用线段只计算一次 |
| \(N_{\mathrm{via}}\) | 过孔总数 |
| \(P_{\mathrm{loss}}\) | 指定工况下的损耗；也可以事先定义为多个工况中的最大损耗 |
| \(C_{\mathrm{total}}\) | 器件、制板及装配成本 |
| \(L_0,N_0,P_0,C_0\) | 事先选定的正参考值，用于归一化 |
| \(\alpha,\beta,\gamma,\delta\) | 各目标的权重，取非负数，并约定总和为 \(1\) |
| \(X^*\) | 在上述模型中取得最低目标值的设计 |

[C] **归一化可以避免把毫米、瓦和金额直接相加。** 权重表达你对不同目标的取舍；改变权重，最优方案可能随之改变。

[C] \(\operatorname{arg\,min}\) 的意思是“找出使括号内数值最小的设计”。它定义了求解目标，本身不提供求解步骤，也不保证解唯一或一定存在。

## 2. 真正决定板子能否工作的，是 \(\mathcal F\)

[I] 这个模型至少应包含以下约束；电气和热约束应覆盖规定的输入电压、负载、环境温度及器件容差范围。

| 约束类别 | 数学条件或明确要求 |
|---|---|
| **连接正确** | 每个网络内的全部引脚连通；不同网络之间不得出现未定义的铜连接 |
| **布局合法** | 元件满足安装边界、位置及方向要求；器件之间无机械碰撞 |
| **制造可行** | 线宽 \(w_e\ge w_{\min,e}\)；同层异网铜间距 \(d_{kh}\ge s_{kh}\)；满足过孔、板边和禁布规则 |
| **电路功能** | 电路方程 \(F_{\mathrm{circuit}}(X,u)=0\)，并且输出指标 \(y(X,u)\in\mathcal Y_{\mathrm{spec}}\) |
| **供电与温度** | 电源压降 \(\lvert\Delta V_n\rvert\le\Delta V_{n,\max}\)；器件结温 \(T_j\le T_{j,\max}\) |
| **高速与高频性能** | 对适用信号满足阻抗误差、传播延时差、串扰、损耗及电磁兼容指标，例如 \(\lvert Z_k-Z_k^{\mathrm{target}}\rvert\le\varepsilon_{Z,k}\)、\(\lvert\tau_a-\tau_b\rvert\le\Delta\tau_{\max}\) |

[I] 其中，\(u\) 表示工作条件；\(\mathcal Y_{\mathrm{spec}}\) 是允许的输出范围，例如输出电压、增益、带宽、纹波或时序要求。具体指标必须来自电路需求和器件规格。

[K] 布线设计规则会涉及连接、线宽、间距、过孔以及长度匹配；高速设计还需要考虑传播延时、阻抗、串扰和回流路径。[KiCad](https://docs.kicad.org/9.0/en/pcbnew/pcbnew.html?utm_source=chatgpt.com)

[C] **连接正确和性能达标必须作为硬条件。** 如果只是给短路、漏连设置一个有限罚分，求解器仍可能因为“线特别短、成本特别低”而选中错误方案。

## 3. “整板怎么连接”，可以这样写成数学约束

[K] 在已有原理图的布局布线任务中，网表规定哪些引脚属于同一个网络；布线负责在板上实现这些连接。[KiCad](https://docs.kicad.org/9.0/en/pcbnew/pcbnew.html?utm_source=chatgpt.com)

[I] 对某一次候选布局，建立一个包含各铜层可走位置、线段和过孔的布线图。对每个网络 \(k\)，定义：

- [I] \(P_k\)：该网络必须连接的引脚集合。
- [I] \(r_k\)：从中任选的一个根引脚。
- [I] \(m_k=|P_k|-1\)：其余引脚的数量。
- [I] \(z_{k,\{v,u\}}\in\{0,1\}\)：网络 \(k\) 是否使用节点 \(v,u\) 之间的候选线段。
- [I] \(f_{kvu}\ge0\)：用于证明连通性的**虚拟流量**，与真实电流分开定义。

[C] 用下面的约束保证该网络所有引脚相连：

\[
\boxed{
\begin{aligned}
\sum_u f_{kvu}-\sum_u f_{kuv}
&=
\begin{cases}
m_k, & v=r_k,\\
-1, & v\in P_k\setminus\{r_k\},\\
0, & \text{其他节点},
\end{cases}
\\[4pt]
0\le f_{kvu}
&\le m_k\,z_{k,\{v,u\}}.
\end{aligned}
}
\]

[K] 这里使用了网络流的节点守恒关系：流出量减流入量等于该节点的供给量或需求量。[developers.google.com](https://developers.google.com/optimization/flow/mincostflow?utm_source=chatgpt.com)

[C] 第一行要求根引脚向每个其他引脚输送一单位虚拟流；第二行要求虚拟流只能经过实际选中的线段。因此，每个其他引脚都必须有一条通向根引脚的路径。

[C] 选中哪些线段以后，总线长可以计算为：

\[
L_{\mathrm{total}}
=
\sum_k\sum_e \ell_e z_{k,e}
\]

[I] 这里 \(e\) 是候选导线段，\(\ell_e\) 是其实际长度。布局变化时，引脚位置和可走路径也必须同步更新；异网之间的间距、交叉和过孔冲突仍由上一节的几何约束限制。

[C] 这部分解决的是：**一个已确定的网络怎样在板上连接起来。** 它不能单独决定某两个芯片引脚在电路功能上是否应该连接。

## 4. 电路参数怎样进入这个公式？

[K] 例如，对截面均匀的直流铜走线，电阻可按电阻率、长度和截面积计算。[ti.com](https://www.ti.com/lit/ug/tiducs7/tiducs7.pdf?utm_source=chatgpt.com)

[C] 因而，单段走线的电阻、压降和铜损可以写成：

\[
\boxed{
R_e=\rho(T_e)\frac{\ell_e}{w_e t_e},
\qquad
\Delta V_e=I_eR_e,
\qquad
P_e=I_e^2R_e
}
\]

[I] 其中，\(\rho(T_e)\) 是对应温度下的铜电阻率，\(w_e\) 是线宽，\(t_e\) 是铜厚，\(I_e\) 是电路计算得到的真实电流。

[C] 这样，布局和走线长度影响电阻，电阻影响压降和损耗，损耗再进入总目标与热约束，几个设计问题就建立了数学联系。

[K] 高速信号还会受到传输线效应、反射和串扰影响，需要相应的传输线或电磁模型。[ti.com](https://www.ti.com/lit/an/scaa082a/scaa082a.pdf?utm_source=chatgpt.com)

[I] 如果你还希望**自动决定原理图连接和元件参数**，可以把电路拓扑与器件选择也放进 \(X\)，但必须提供器件模型和功能指标。仅要求满足电流、电压守恒，无法指定电路应实现什么功能。

## 适用性判断

| **Supporting Arguments** | **Opposing Arguments** |
|---|---|
| [I] 统一模型可以把连接、布局、布线和电气指标放进同一求解框架，明确比较不同方案的取舍。 | [I] 模型依赖完整输入和可信的物理计算；写出目标函数，并不意味着已经获得整板全局最优解。 |

**Net Judgment：[I] 这个公式能够定义“在给定要求下最优的PCB”。要计算具体引脚连接、元件坐标和走线，还需要原理图或功能规格、器件与封装、板框、叠层、制造规则及电气指标。你目前提供的信息足以建立通用模型，尚不足以算出一块具体板。**
