说明

与 AI 智能体的区别

本文介绍在 Cursor / IDEA 里编写 EC 脚本。若您 不想写代码，请使用新中控内置的 AI 智能体（中文对话 + 可视化工作流）。

提示

  • 该教程基于 9.27.0+ 开发插件版本，中控任何版本都支持
  • 编程工具使用的是Cursor和IDEA
  • IDEA作为全功能版本，包含了新建工程等，Cursor作为辅助编程、自动纠错和编译运行工具
  • 所有大模型都可以支持，不仅限于Cursor等，配置方式都是类似
  • iOS USB版本和脱机版本 使用的方式是相同的，唯一区别是 iOS USB版本不能预览UI，脱机版本可以

重要提示

  • 开发插件安装好后，找到IDEA顶部的菜单，再依次找到安装 AI DOCS，会自动将所有的API文档放到工程目给AI读取
  • 后面的给AI喂文档的就不要了，让AI读取alldocs文件夹中的API函数和规则即可

配置 MCP（可不使用 CLI）

如果不想使用 CLI，可在 Cursor 等 AI 编程工具里直接配置 MCP 服务，由 IDEA 插件提供预览、运行、截图、OCR、节点抓取等能力。

前提：本机已启动 IntelliJ IDEA，并打开了 EasyClick 工程（插件已加载）。

使用Cursor编程

打开工程

  • 使用Cursor打开文件夹的功能，选择你的工程文件夹，不要选择到模块
  • 跟AI对话，让AI理解工程，并且扫描工程结构和SKILL.md

编译IEC文件

  • 跟AI对话，让AI编译，例如编译testai工程

预览工程

  • 前提是有设备链接到IDEA,否则会提示无设备连接
  • 跟AI对话，让AI编译，例如预览testai
  • 注意：iOS USB版本工程无法预览，只有iOS脱机版本才能预览

运行工程

  • 前提是有设备链接到IDEA,否则会提示无设备连接
  • 跟AI对话，让AI编译，例如运行testai
  • 让Cursor编写业务逻辑后运行验证结果

投喂文档给AI

  • 在和AI对话框中输入@符号，选择Docs，再次选择Add new doc，把EC的文档地址喂给AI，让AI自己抓取并理解

更多功能

  • 让AI自动代码、自助分析日志的功能，需你自己摸索，CLI提供的命令是为了告诉发生了什么，AI再去分析如何去做
