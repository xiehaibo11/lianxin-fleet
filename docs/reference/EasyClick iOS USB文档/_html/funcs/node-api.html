节点函数

说明

  • 节点模块函数主要是跟节点操作相关联
  • 该模块没有模块前缀，可以直接调用函数
  • 由于IOS的限制，可能部分机器获取节点过慢，建议获取节点后进行锁定节点后，在进行查找
  • 也可以使用设置节点获取参数的方式进行
  • 不适合的页面：比如适配播放页面等

锁定节点三种方式：

函数适用场景说明
lockNodeUSB 直连经 USB 从手机拉 XML 并锁定到 PC 缓存
lockNodeFromXmlWiFi + Aux将 auxEvent.agentDumpXml() 等外部 XML 注入 PC 缓存并锁定（适配 9.39.0+）
releaseNode通用释放锁定，恢复为界面刷新后重新拉取

WiFi 场景完整流程见 lockNodeFromXml；对象形式可用 agentEvent.lockNodeFromXml(xml)，见 代理事件。

setFetchNodeParam 设置节点参数

  • 设置获取节点的基础参数，这个参数可以有效减少获取节点的数量和消耗的时间
  • 支持版本: EC iOS 中控 3.0.0+
  • 重要：请与 IDEA「节点调试设置」保持一致（maxDepth / maxChildCount / excludedAttributes / visibleFilter / labelFilter / boundsFilter）。IDEA 能抓到、代码抓不到时，多半是两边参数不一致；代码未调用本函数时会用运行时默认（如 maxDepth=30、maxChildCount=30），与 IDEA 工程里保存的设置可能不同
  • @param ext 是一个map，例如 {"visibleFilter":1,"maxDepth":"60","maxChildCount":"0","excludedAttributes":""}
  • visibleFilter 1 代表不管visible是true还是false都获取，2 代表只获取 visible=true的节点
  • labelFilter 1 代表不管label是否有值都获取，2 代表只获取label有值的节点
  • boundsFilter 1 代表不过滤 2 bounds 区域属性x,y,w,h都小于0就被过滤
  • maxDepth 代表要获取节点的层级，默认 30，建议 15–30（抖音等宽树别盲目加大）
  • maxChildCount 每层最大子节点数，默认 30；0 表示设备端默认。抖音等宽树建议 ≤30
  • excludedAttributes 代表要过滤的属性，用英文逗号分割，可以增加抓取速度，例如 visible,selected,enable；需与 IDEA 一致时按 IDEA「节点调试设置」填写（含空串表示不排除）
  • @return {bool} true 成功，false 失败

lockNode 锁定节点

  • 经 USB 从手机拉取节点 XML 并锁定到 PC 侧缓存；锁定后界面刷新也不会更新已缓存的节点树，需配合 releaseNode 解锁
  • 支持版本: EC iOS 中控 3.0.0+
  • 与 setFetchNodeParam 配合可缩小抓取范围、加快速度

lockNodeFromXml 从 XML 锁定节点

  • 将外部 XML 字符串注入 PC 侧节点缓存并锁定，可与 auxEvent.agentDumpXml 配合，再继续使用本模块的选择器（label().getNodeInfo() 等）
  • 适配版本 EC iOS 中控 9.39.0+
  • 对象形式：agentEvent.lockNodeFromXml(xml)，见 代理事件 - lockNodeFromXml
  • @param xml XML 字符串（如 auxEvent.agentDumpXml() 的返回值）
  • @return {bool} true 成功，false 失败

releaseNode 释放节点

  • 释放节点锁定；释放后 getNodeInfo 等会按最新界面重新拉取 XML
  • 支持版本: EC iOS 中控 3.0.0+
  • 与 lockNode、lockNodeFromXml 配对使用

getNodeInfo 获取节点集合

  • timeout 超时时间，单位毫秒
  • 支持版本: EC iOS 中控 3.0.0+
  • @return {array} 节点对象集合

getOneNodeInfo 获取单节点

  • timeout 超时时间，单位毫秒
  • 支持版本: EC iOS 中控 3.0.0+
  • @return {NodeInfo} 节点对象
