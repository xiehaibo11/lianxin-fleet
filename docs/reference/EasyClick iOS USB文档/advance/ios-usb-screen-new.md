# 新界面操作指引

本章节介绍全新投屏界面的操作方式。请先在[主教程](ios-usb-screen.md)中完成软件下载、签名 IPA、配置镜像等准备工作。

> **提示：USB投屏使用指南视频教程**
>
> - 地址是 : <https://space.bilibili.com/477518868/lists/8622038?type=season>
> - 用来讲解EasyClick iOS USB版本投屏的功能，比如同步操作投屏、输入文字、点击、上传视频和图片、操作手机剪切板、录制脚本等等

## 如何进入

1. 启动并登录中控
2. 在顶部工具栏点击 **集控投屏**
3. 在弹出对话框中选择 **全新界面**（推荐），点击确定
4. 等待投屏客户端窗口打开

## 界面概览

进入后你会看到以下区域：

| 区域 | 说明 |
| --- | --- |
| 侧边栏 | 左侧工作区和更多工具两个标签页 |
| 设备列表 | 显示所有已连接的设备，支持多选 |
| 主控窗口 | 中心区域，显示当前主控设备的屏幕 |
| 小屏幕 | 可拖拽的设备缩略图，右键可弹出操作菜单 |
| 系统设置 | 侧边栏或工具栏中可进入设置面板 |

## 启动自动化

> **提示**
>
> 启动自动化需要回到中控界面操作，不在投屏客户端内进行。启动自动化前，请先在中控确认：
>
> - 代理 IPA 已签名并安装到手机
> - 开发者镜像已正确放置
> - 在中控的系统设置中已填写代理 IPA 的 BundleId 前缀
> - 投屏客户端的 IPA 包名设置中也同样填写一份（侧边栏或工具栏中找到「IPA包名」入口）

1. 返回中控主界面，确认手机通过 USB 数据线连接到电脑，爱思助手能识别设备
2. 在中控的设备列表中，右键要操作的设备，选择 **开启自动化**
3. 等待片刻，设备列表中「服务状态」一栏变为蓝色 **是**，表示启动成功
4. 如果超过 1 分钟未成功，请右键选择 **测试自动化** 查看具体错误信息
5. 自动化启动成功后，再回到投屏客户端进行后续操作

> **提示**
>
> 首次启动成功后，后续只需在投屏客户端中直接点击 **开始投屏** 即可，无需每次回到中控操作。自动化服务会在后台保持运行。

> **注意**
>
> 如果后面选择的是 **无自动化截图 + USB\_HID** 或 **主程序录屏 + USB\_HID**，一般不用先做本节的「开启自动化」；只有选「USB + 自动化服务」时才需要。

## 怎么选投屏方式

打开投屏客户端的 **系统设置**，用 **场景模式** 选一种方式，再点 **开始投屏**。对照下表选即可：

**USB\_HID**（含「无自动化截图 + USB\_HID」「主程序录屏 + USB\_HID」）和 **蓝牙 USB\_BLE** 都要求手机系统为 **iOS 17 及以上**。低于 iOS 17 请使用「USB + 自动化服务」。

| 你想怎么用 | 请选这个场景 | 手机上要准备什么 |
| --- | --- | --- |
| 传统方式：装代理 App，功能最全 | **USB + 自动化服务** | 安装代理 IPA（或用脱机主程序当代理），并在中控里开启自动化 |
| 不想装 App，用蓝牙板控制 | **无自动化截图 + USB\_BLE** | 手机 **iOS 17+**，并准备好蓝牙开发板 |
| 不想装 App，也不想用蓝牙板 | **无自动化截图 + USB\_HID** | 手机 **iOS 17+**，USB 连上电脑即可 |
| 画面更流畅，用手势点手机 | **主程序录屏 + USB\_HID** | 手机 **iOS 17+**；到[下载区](https://ieasyclick.com/community/download_area)下载已签名的脱机主程序 IPA，可直接安装；投屏时若弹出「开始直播」，点一下确认 |

不确定时，可先试 **无自动化截图 + USB\_HID**（最简单，需 iOS 17+）；需要更好画面或要用自定义输入法、主程序剪贴板等，再选 **主程序录屏 + USB\_HID**。

### 无自动化截图 + USB\_HID（免装 App）

需 **iOS 17+**。

1. 系统设置 → 场景模式 → 选 **无自动化截图 + USB\_HID**
2. 点 **开始投屏**，等主窗口出现手机画面
3. 用鼠标点击、滑动即可操作手机

> **提示**
>
> - 鼠标点手机没反应时：在设备小屏幕或设备列表上 **右键** → **USB HID** → **重建 USBHID 会话**，再试点击。
> - 用过本方式后，如果再改回「USB + 自动化服务」发现投屏不正常，请先**重启手机**再试。
> - 用电脑往手机打英文时如果总是多出空格，可在手机「设置 → 通用 → 键盘」里关掉「智能标点」。

### 主程序录屏 + USB\_HID

需 **iOS 17+**。

1. 到[下载区](https://ieasyclick.com/community/download_area)下载 **脱机主程序** IPA（已签名，可直接安装到手机并打开）。若从网盘下载同款 IPA，需自行签名后再安装
2. 在中控或投屏的「IPA 包名」里填好该主程序的包名
3. 系统设置 → 场景模式 → 选 **主程序录屏 + USB\_HID**
4. 点 **开始投屏**；手机若弹出「开始直播 / 广播」，请点确认
5. 需要时，可点侧边栏或状态栏的 **打开主程序/Runner**，把主程序切到前台

本方式下：鼠标点击、滑动照常可用；复制文字、打开链接、传相册等会尽量走脱机主程序，一般更省事。若点击没反应，同样可在设备上 **右键 → USB HID → 重建 USBHID 会话**。

## 开始投屏

1. 在系统设置里选好上面的场景
2. 如果选的是「USB + 自动化服务」，请先确认已开启自动化
3. 点侧边栏或工具栏里的 **开始投屏**
4. 稍等几秒，主控窗口会出现手机画面
5. 可用鼠标直接操作；滑动方式可在系统设置里调整

## 常用操作

### 打字输入

在系统设置的 **输入法设置** 里二选一：

- **系统默认**：按当前投屏方式自动发送文字（多数情况够用）
- **自定义输入法**：请先到[下载区](https://ieasyclick.com/community/download_area)下载已签名的 **脱机主程序** 并直接安装（网盘 IPA 需自行签名）；具体怎么开键盘、怎么授权，请点设置里的 **键盘设置说明**

一句话：自定义输入法 = 下载区安装脱机主程序 + 按「键盘设置说明」操作。

### 脚本录制

- 点击侧边栏的 **录制脚本** 按钮
- 新建脚本后点击 **开始录制**，在主控窗口上操作手机
- 录制完成后保存，即可选择执行
- 注意：必须在主控窗口上操作才能录制，运行脚本需要 USB 设备授权

### 上传图片 / 视频

- **iOS 15+**：使用工具栏中的 **上传视频** 或 **上传图片** 按钮；也可在小屏幕上右键 → 图片视频 进行操作
  - 支持 **选择文件夹** 批量上传，或 **选择图片/视频** 单个上传
- **iOS 15 系统版本以下**：需要使用 **文件助手功能**，需额外安装文件助手 IPA，在文件助手弹窗中按说明配置
- 若当前是 **主程序录屏**，传相册时请尽量保持脱机主程序可用（必要时点 **打开主程序/Runner**）

### 剪贴板操作

#### 复制文字到手机

- 点击工具栏中的 **复制文字** 按钮
- **主程序录屏**：一般直接发即可；不行时先点 **打开主程序/Runner**
- **自动化投屏**：iOS 15+ 请先点 **打开IPA**，再发送文字
- iOS 15 系统版本以下需使用文件助手功能

#### 读取手机剪贴板

- 在小屏幕上右键 → 剪贴板 → **读取剪贴板数据到电脑**
- **主程序录屏**：一般直接读即可
- **自动化投屏**：iOS 15+ 请先把代理 IPA 打开到前台

### 打开网址 / 应用

- **主程序录屏**：可直接打开网址或应用（按界面提示填写即可）
- **自动化投屏（iOS 15+）**：用工具栏 **打开应用**，按提示先打开代理 IPA，再填写
- iOS 15 系统版本以下：需使用文件助手功能

### 其他

- 使用 **USB\_HID** 相关场景时，若画面有、但鼠标操作手机没反应：设备小屏幕或列表上 **右键 → USB HID → 重建 USBHID 会话**
- 闪断 USB、重启设备、重启通信隧道等操作，可在设备右键菜单或工具栏中找到
- 自动化启动不成功时，可尝试闪断 USB；iOS 17+ 可尝试重启通信隧道
