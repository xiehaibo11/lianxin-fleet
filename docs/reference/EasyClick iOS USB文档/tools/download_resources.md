# 下载开发工具

开始写脚本前，先下载 IDEA、开发插件与相关资源。装好后继续 [安装开发工具](installreadme.md)，再 [创建第一个工程](../firstproject.md)。

> **提示**
>
> **推荐一键下载安装**：打开 [下载区域](https://ieasyclick.com/community/download_area/)，用产品下载器勾选所需组件，可快速下载并完成配置。需要单独取文件时，再用下方网盘地址。

## Idea开发工具

> **提示**
>
> **推荐使用官方正版 IDEA 2026.2 及以上**：请到 [JetBrains 官网](https://www.jetbrains.com/idea/download/) 下载安装，再安装 EasyClick 开发插件即可。旧版本后续将不再支持，请统一使用 2026.2+。
>
> 如果不适应新的 IDEA UI：打开 IDEA **设置 → 插件**，搜索 **Classic UI** 并安装，**重启 IDEA** 后即可恢复经典界面。

- 下载idea开发工具，文件以idea-xxx开头的，也可以自行到idea官网下载，下载并安装idea到电脑，然后安装对应开发插件到idea中
- IDEA下载地址：2026.2.win.zip <https://download.jetbrains.com/idea/idea-2026.2.win.zip>
