# 开发环境安装

- 123网盘：<https://www.123pan.com/s/6Hlmjv-QayIA.html>
- QQ群下载：777164022
- 下载idea开发工具，文件以idea-xxx开头的，也可以自行到idea官网下载
- **推荐使用官方正版 IDEA 2026.2 及以上**：请到 [JetBrains 官网](https://www.jetbrains.com/idea/download/) 下载安装，再安装 EasyClick 开发插件即可。旧版本后续将不再支持，请统一使用 2026.2+
- 如果不适应新的 IDEA UI：打开 IDEA **设置 → 插件**，搜索 **Classic UI** 并安装，**重启 IDEA** 后即可恢复经典界面
- IDEA官网下载地址
- 网页地址：<https://www.jetbrains.com/idea/download/>
- 历史版本（可选）：<https://www.jetbrains.com/idea/download/other.html>

  - 商业版本JS智能提示：2026.2 <https://download.jetbrains.com/idea/idea-2026.2.win.zip>
- 安装后，打开bin/idea64.exe文件开始运行
    
  ![getstart 1](https://ieasyclick.com/iosimg/getstart-1.jpg)
- 下载EasyClick最新版本的IDEA插件，并按照到IDEA中，安装教程：<https://blog.csdn.net/qq_35246620/article/details/78289074>
