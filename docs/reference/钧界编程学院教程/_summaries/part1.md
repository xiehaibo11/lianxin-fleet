## 对联信 Fleet 有参考价值的要点

- 《群控运行脚本》：iOS 免越狱路线可走 Switch Control + USB HID（iOS 13+），HID 只能输出、不能读屏，需另配截图/状态回传；原文技术细节未验证。
- 《群控运行脚本》：HID 指令间隔 0.1s 会吞事件，建议 0.3-0.5s；滚动用增量 delta（3-5）而非绝对坐标；每次写入后加约 5ms 间隔可缓解断连。
- 《群控运行脚本》：坐标按逻辑点（如 375x667、390x844），用「坐标/基准宽度*目标宽度」做多机型比例映射。
- 《群控运行脚本》：多机并行按 USB 序列号区分设备（hidraw 编号会漂移），维护序列号到脚本的映射；每台一线程、threading.Event 同步，12 台 0.5s 频率可行。
- 《群控运行脚本》：物理层要点：带独立电源的 USB Hub、数据线 <1.5m、MFi 线，否则出现“电缆未认证”弹窗与丢包；引导式访问可防误触退出 App。
- 《群控运行脚本》：每台设备每轮写独立 CSV 日志（耗时、最后点击坐标、截图路径），并做“状态自查”（读像素判断是否回到首页，否则强制重启 App）。
- 《02-EasyClick 官方》：EC iOS 产品分 USB 版（13-18，需插线，中控+投屏）与脱机版（15-18，局域网中控/投屏，可打包 IPA）；中控批量控制脚本/设备/参数，可对接云控，可作为 Fleet 功能对标。
- 《02-EasyClick 官方》：网络验证内置心跳、云端变量、外放/回收卡密；云控需自备服务器，集中管理任务、脚本、参数、数据、投屏，可参考其授权与中心管理设计。
- 《02-EasyClick 官方》《11-EasyClick 远程调试内网穿透工具》：官方有面向 iOS 开发工具与 HID 主控的免费远程调试，异地接入可用 frp/frpmgr/花生壳。
- 《01-钧界编程学院/02-AI 编程智能体服务》：商用脚本常见风险（封号风控、双端 UI 差异、节点树卡死、授权交付）可作为 Fleet 脚本模板自检项（仅广告页，无技术细节）。
