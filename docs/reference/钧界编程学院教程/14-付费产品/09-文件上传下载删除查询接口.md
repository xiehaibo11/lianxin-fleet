# 文件上传下载删除查询接口

>d 开源地址 :[老鬼的gitee](https://gitee.com/Mr_laogui/fileuploaddownload)


## 接口请求参数与响应

### 1. 自适应文件上传

**请求方法**: POST

**请求参数**:
- 文件上传 (multipart/form-data):
  - 多文件上传: 使用不同字段名 (file1, file2, file3...)
- JSON列表 (application/json):
  ```json
  {"file1":"name1","file2":"name2"}
  ```
  或
  ```json
  ["file1","file2","file3"]
  ```
- 表单提交 (application/x-www-form-urlencoded):
  - file1=name1&file2=name2 格式

**响应**:
```json
{
  "message": "成功上传 3 个文件 (总大小: 2.5 MB)",
  "files": [
    {
      "originalname": "原始文件名.jpg",
      "filename": "唯一文件名-时间戳.jpg",
      "size": 文件大小,
      "sizeText": "2.5 MB",
      "mimetype": "文件MIME类型",
      "fieldname": "file1"
    }
  ],
  "uploadType": "multiple-any",
  "totalSize": 总文件大小
}
```

### 2. 文件下载

**请求方法**: GET

**请求参数**:
- URL路径: `/download/:filename`
- 参数: filename (上传时返回的唯一文件名)

**响应**: 文件流下载

### 3. 获取文件列表

**请求方法**: GET

**请求参数**:
- GET请求，无需参数

**响应**:
```json
{
  "message": "共 5 个文件",
  "totalSize": "15.2 MB",
  "files": [
    {
      "filename": "文件名-时间戳.jpg",
      "size": 文件大小,
      "sizeText": "3.1 MB",
      "createdAt": "创建时间",
      "modifiedAt": "修改时间"
    }
  ]
}
```

### 4. 删除文件

**请求方法**: DELETE

**请求参数**:
- URL路径: `/files/:filename`
- 参数: filename (文件名)

**响应**:
```json
{
  "message": "文件删除成功"
}
```

## 注意事项

1. 上传文件大小限制为100MB
2. 上传的文件保存在`uploads`目录下
3. 文件名会自动添加时间戳以避免冲突
4. 支持所有文件类型上传
5. 服务器使用标准HTTP状态码表示请求结果（200成功，400客户端错误，500服务器错误等）
6. 所有响应采用统一的错误格式，包含`error`字段描述错误原因
