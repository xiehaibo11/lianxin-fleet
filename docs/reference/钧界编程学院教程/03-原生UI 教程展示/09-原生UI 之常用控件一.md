# EasyClick 原生UI 之常用控件
## TextView 控件
### 私有属性

| 属性名 | 说明 | 可选值 |
|:--- |:--- |:---:   |
| layout_weight | 子元素权重 | 数字 <br>当父级为LinearLayout的时候，子控件可以设置权重 |
| gravity | 内部的控件对齐方式 |  top  <br>bottom <br>left <br> right<br> center_vertical <br>fill_vertical <br>center_horizontal<br> fill_horizontal<br> center <br> fill<br> clip_vertical clip_horizontal
| text | 按钮文字 | 字符串 |
| textColor | 文字颜色 | 16进制，例如#FFFFFF |
| textSize | 文字大小 | 具体数字+dp |
| maxLength | 文字最大长度 | 具体数字 |
| lines | 行数 | 具体数字 |
| maxLines | 最大 | 具体数字 |
| ellipsize | 文字长度超过宽度时的显示方式 | start:省略号显示在开头  <br> end:省略号显示在结尾 <br> middle:省略号显示在中间 <br>marquee:以横向滚动方式显示(需获得当前焦点时)<br> none:不显示 |

说明：textview控件 部分属性需要代码写法才会生效，xml 写法因为ec问题导致不生效。
xml不生效的：ellipsize属性。lines
其他属性不生效请查看是否写错值了。
maxLength这个属性需要设置宽度才会生效.
maxLines、lines这2个属性需要设置高度才会生效。


### 例子
```xml
 <TextView android:layout_width="wrap_content"
           android:layout_height="wrap_content"
           android:layout_weight="1"
           android:lines="10"
           android:ellipsize="end"
           android:textColor="#000000"
           android:gravity="center"
           android:maxLength="100"
           android:text="姓名: " />
```
## button  控件
### 私有属性


| 属性名 | 说明 | 可选值 |
|:--- |:--- |:---:  |
| layout_weight | 子元素权重 | 数字 <br> 当父级为LinearLayout的时候，子控件可以设置权重 |
| gravity | 内部的控件对齐方式 | top <br> bottom <br> left <br> right <br> center_vertical <br> fill_vertical <br> center_horizontal <br> fill_horizontal center <br> fill clip_vertical <br> clip_horizontal |
| text | 按钮文字 | 字符串 |
| textColor | 文字颜色 | 16进制，例如#FFFFFF |
| textSize | 文字大小 | 具体数字+dp |
| maxLength | 文字最大长度 | 具体数字 |

### 例子
```xml
 <Button android:layout_height="wrap_parent"
         android:layout_width="match_parent"
         android:tag="btn"
         android:text="按钮"
         android:textColor="#669999"
         android:textSize="14dp"
         android:gravity="center"
/>
```
## EditText   输入框控件
### 私有属性


| 属性名 | 说明 | 可选值 |
|:--- |:--- |:---: |
| layout_weight | 子元素权重 | 数字 <br> 当父级为LinearLayout的时候，子控件可以设置权重 |
| gravity | 内部的控件对齐方式 |   top<br>bottom <br>left<br> right<br>center_vertical<br>fill_vertical<br>center_horizontal<br>fill_horizontal<br>center<br>fill<br>clip_vertical<br>clip_horizontal|
| hint | 输入提示 | 字符串 |
| text | 文字 | 字符串 |
| textColor | 文字颜色 | 16进制，例如#FFFFFF |
| textSize | 文字大小 | 具体数字+dp |
| maxLength | 文字最大长度 | 具体数字 |
| lines | 行数 | 具体数字 |
| maxLines | 最大 | 具体数字 |
| ellipsize | 文字长度超过宽度时的显示方式 | start:省略号显示在开头<br>end:省略号显示在结尾<br>middle:省略号显示在中间<br>marquee:以横向滚动方式显示(需获得当前焦点时) <br> none:不显示
| inputType | 输入框类型 | text:文本 <br>phone:号码<br>number:数字<br>textPassword:文本密码 <br>numberPassword:数字密码 |


### 例子

```xml
<EditText android:layout_height="wrap_parent"
          android:layout_width="match_parent"
          android:tag="btn"
          android:text="按钮"
          android:textColor="#669999"
          android:textSize="14dp"
          android:gravity="center"
          android:maxLength="12"
          android:hint="我是提示"
    />
```

## View最基本的视图控件
说明：View，最基础的视图
### 私有属性
无， 这个是最基本的视图，所有的控件，布局都继承于它，只有公有属性没有私有属性，公有属性参考公有属性篇。
### 例子
```xml
 <View android:visibility="visible"
	   android:clickable="true"
	   android:padding="1dp"
	   android:background="#FFFFFF"
	   android:layout_gravity="center|top"
	   android:layout_height="match_parent"
	   android:layout_margin="1dp"
	   android:layout_marginBottom="1dp"
	   android:layout_marginLeft="1dp"
	   android:layout_marginRight="1dp"
	   android:layout_marginTop="1dp"
	   android:layout_weight="1"
	   android:layout_width="wrap_parent"
	   android:minHeight="100dp"
	   android:minWidth="100dp"
	   android:paddingBottom="1dp"
	   android:paddingLeft="1dp"
	   android:paddingRight="1dp"
	   android:paddingTop="1dp"
	   android:cornerRadius="10dp"
	   android:tag="view"/>
```
