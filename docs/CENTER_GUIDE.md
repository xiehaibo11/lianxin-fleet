# 中控使用说明

Windows 桌面程序和 macOS 版（安装与差异见 [MAC_GUIDE.md](MAC_GUIDE.md)）启动后都进入「中控」主窗口，顶部有四个标签：设备、AI 助手、定时任务、设置。原来的设备墙改为「集控投屏」窗口，从设备页工具栏打开，两边共用同一个数据库、任务队列和自动化通道。

## 设备页

- 用数据线连接 iPhone、解锁并点「信任此电脑」后，中控会自动登记，表格显示设备 ID、别名、名称、型号、系统、ECID、分组、连接方式、脚本、消息和自动化状态。
- 「列设置」选择显示哪些列，结果保存在设置里。表格右键可以设置别名、移到分组、测试自动化、复制设备 ID。
- 左侧分组：「添加」新建空分组；勾选「多选」后可同时筛选多个分组；右键可把勾选的设备移入分组，或删除分组（组内设备回到「未分组」）。
- 工具栏按钮作用于勾选的设备；没有勾选时，「启动自动化」「停止自动化」「停止脚本」作用于全部符合条件的设备。
- 底部状态栏：中控和桥接（Apple 设备服务）是否正常、总数、未就绪（在线但自动化未启动）、在线、正在运行的脚本数，以及刷新间隔。

## 自动化与一键配置

自动化就是在手机上运行签名的 WDA Runner。首次使用前，在「设置」里填好 WDA Runner Bundle ID，把签名的 WDA 安装包放进应用批准目录，然后：

1. 勾选设备，点「一键配置」，按需勾选：开启开发者模式（iOS 16 及以上，手机会重启，需要先关闭锁屏密码）、挂载开发者镜像（首次需要联网下载）、安装 WDA。最多 4 台同时配置，逐台显示进度。
2. 在手机「设置 → 通用 → VPN 与设备管理」信任开发者。
3. 点「启动自动化」。自动化列变为「是」即可运行脚本、使用 AI 助手和集控投屏的鼠标控制。手机重启后开发者镜像会失效，需要重新挂载。

「重置 USB」会停止全部脚本和通道，并通过管理员授权重启 Apple Mobile Device Service，适合手机识别异常时使用。

## 脚本

脚本在电脑端通过 WDA 逐步执行，每行一个命令，`#` 开头为注释。坐标是 0–1 的相对位置（左上角 `0 0`，右下角 `1 1`），时间单位为秒。

| 命令 | 说明 |
| --- | --- |
| `点击 x y`、`双击 x y`、`长按 x y [秒]` | 屏幕点按 |
| `滑动 x1 y1 x2 y2 [秒]`、`上滑`、`下滑`、`左滑`、`右滑`、`返回` | 滑动手势 |
| `输入 文字`、`剪贴板 文字` | 向当前输入框输入，或写入剪贴板 |
| `启动 BundleID`、`关闭 BundleID`、`打开 网址` | 应用与链接 |
| `主屏`、`锁屏`、`解锁`、`音量加`、`音量减`、`多任务` | 系统按键 |
| `等待 秒` | 0.05–3600 秒 |

英文命令同样可用（`tap`、`swipe`、`text`、`launch`、`wait`、`home` 等）。运行次数为 0 时一直循环，直到手动停止。同一台手机同一时间只运行一个脚本，最多 32 台同时运行；出错时该设备停止并在「消息」列显示第几步失败。程序异常退出时，运行中的脚本记为「待确认」，不会自动重跑。

EasyClick 等其他工具的 JS 脚本不能直接运行，需要按上面的命令改写。

## 定时任务

按本机时间对全部设备、某个分组或指定设备运行脚本，支持「每天定时（可选星期）」和「每隔 N 分钟」。只在中控运行期间生效，关闭期间错过的任务不补跑；每天模式到点后 10 分钟内仍会触发。到点时目标设备正在运行其他脚本，会在那个脚本结束后自动补跑（每天模式限到点后 10 分钟内，间隔模式限一个间隔内）。被定时任务使用的脚本和分组不能删除。

## AI 助手

选择一台已启动自动化的手机，用一句话描述任务，AI 会看截图、逐步操作，直到调用结束或达到最多轮数。默认模型 `claude-opus-5-5`，已开启服务端拒答回退（`server-side-fallback-2026-07-01`）。API 密钥可在设置里填写（按当前 Windows 用户 DPAPI 加密保存），也可用环境变量 `ANTHROPIC_API_KEY` 或 `ant auth login`。截图会发送给模型服务，按 token 计费；结果区显示本次输入、输出 token 数。

AI 不会主动输入密码、付款、发送消息或删除数据，遇到登录、验证码等情况会停下说明原因。

## 无线中心

对 USB 已信任的手机开启「Wi-Fi 连接」后，拔掉数据线、与电脑在同一局域网时仍可被识别（连接列显示 Wi-Fi），自动化与投屏走无线。Windows 需要安装 Bonjour，Apple 设备服务才能发现无线手机；无线中心会检查并提示。目前支持 iOS 16 及以下的无线控制，iOS 17 及以上需要额外的隧道服务，暂不支持。

## 数据与设置

数据目录默认 `%LOCALAPPDATA%\LianxinFleet`（可用 `FLEET_DATA_DIR` 覆盖），包含 `fleet.sqlite`、`settings.json`、`wda-runner.txt` 和应用批准目录 `apps`。旧数据库首次打开时自动补充新列和新表，不改动已有数据。
