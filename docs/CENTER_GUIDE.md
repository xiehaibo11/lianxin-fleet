# 中控使用说明

Windows 桌面程序和 macOS 版启动后都进入「中控」主窗口，顶部有四个标签：设备、AI 助手、定时任务、设置。设备墙是从设备页工具栏打开的「集控投屏」窗口，与中控共用同一个数据库、任务队列和自动化通道。两个平台的功能相同，Mac 上的安装和少数差异见 [MAC_GUIDE.md](MAC_GUIDE.md)。

## 设备页

- 用数据线连接 iPhone、解锁并点「信任此电脑」后，中控会自动登记，表格显示设备 ID、别名、名称、型号、系统、电量、ECID、分组、连接方式、脚本、消息和自动化状态。
- 「列设置」选择显示哪些列，结果保存在设置里。表格右键可以打开设备详情、设置别名、移到分组、测试自动化、复制设备 ID。
- 左侧分组：「添加」新建空分组；勾选「多选」后可同时筛选多个分组；右键可把勾选的设备移入分组，或删除分组（组内设备回到「未分组」）。左侧下方是脚本列表，见下面的「脚本」。
- 工具栏按钮作用于勾选的设备；没有勾选时，「启动自动化」「停止自动化」作用于全部在线或已启动的设备，「停止脚本」「暂停脚本」「继续脚本」作用于全部正在运行脚本的设备。「运行脚本」和「更多 ▾」里的安装、镜像、电源操作必须先勾选设备。
- 底部状态栏：中控和桥接（Apple 设备服务）是否正常、开放接口状态、总数、未就绪（在线但自动化未启动）、在线、正在运行的脚本数，以及刷新间隔。

## 自动化与一键配置

自动化就是在手机上运行签名的 WDA Runner。首次使用前，在「设置」里填好 WDA Runner Bundle ID，把签名的 WDA 安装包放进应用批准目录，然后：

1. 勾选设备，点「一键配置」，按需勾选：开启开发者模式（iOS 16 及以上，手机会重启，需要先关闭锁屏密码）、挂载开发者镜像（首次需要联网下载）、安装 WDA。最多 4 台同时配置，逐台显示进度。
2. 在手机「设置 → 通用 → VPN 与设备管理」信任开发者。
3. 点「启动自动化」。自动化列变为「是」即可运行脚本、使用 AI 助手和集控投屏的鼠标控制。手机重启后开发者镜像会失效，需要重新挂载。

「重置 USB」会停止全部脚本和通道，并经管理员授权重启 Apple 设备服务（Windows 为 Apple Mobile Device Service，macOS 为 usbmuxd），适合手机识别异常时使用。

## 设备管理

以下功能通过 USB（或已开启 Wi-Fi 连接的无线手机）的系统服务完成，不需要先启动自动化，只要手机已信任电脑。

- **电量列**：一次读取全部在线手机的电量，每分钟刷新一次，「⚡」表示正在充电，鼠标停在单元格上可看充电状态和数据来源。USB 读不到而自动化在线的手机改从 WDA 读取。「更多 ▾ → 刷新电量」立即重新读取。
- **设备详情**：表格右键「设备详情…」，打开后有五个标签，同一时间只执行一项操作，进度和错误显示在窗口底部。关闭窗口会中断它发起的操作；上传、删除、卸载、重启等会改动手机的操作进行中时，关闭前先确认：
  - 信息：名称、型号、系统版本、序列号、销售型号、屏幕分辨率、总容量与可用空间、电量、电池温度、循环次数和最大容量。自动化已就绪时电量和屏幕取 WDA 的实时值。
  - 应用：列出用户安装的应用（名称、Bundle ID、版本），可以卸载（应用数据一起删除，系统应用不能卸载）；启动、关闭需要自动化已就绪；「安装应用…」与工具栏的安装相同，只接受应用批准目录里的 .ipa，安装完成后刷新列表。
  - 文件：浏览手机媒体区（/var/mobile/Media，即相册 DCIM、Downloads 等），双击进入文件夹，可上传文件（上传前直接向手机确认是否有同名文件，不受列表是否最新和 1000 项上限的影响，有就提示覆盖）、下载文件或文件夹到本机文件夹（本机已有同名项时拒绝，不会覆盖；下载中途失败不会留下半截的文件）、新建文件夹、删除。手机路径必须以 / 开头，不能含 `..`、`\` 或控制字符；媒体区根目录和 DCIM、Downloads 等系统文件夹本身不能删除，只能删除其中的内容；PhotoData（照片库数据）和 iTunes_Control（音乐库数据）里的任何内容都不能删除、覆盖或新建。列表最多显示 1000 项。上传、删除中途断开时结果标为「待确认」（可能已部分生效）。
  - 开发者镜像：查询是否已挂载（iOS 16 及以下为 Developer 镜像，iOS 17 及以上为 Personalized 镜像）、挂载（与一键配置相同，本机没有时联网下载）和卸载。卸载前会停止这台手机的脚本和自动化。
  - 电源：重启、关机，都要确认，执行前先停止这台手机的脚本和自动化。重启后需要重新挂载开发者镜像并启动自动化；关机后只能在手机上按电源键开机。
- **批量操作**：设备页工具栏「更多 ▾」里的「挂载 / 卸载开发者镜像」「重启 / 关机勾选设备」作用于勾选且在线的设备，最多 4 台同时进行。卸载、重启、关机需要确认，并先停止这些设备上的脚本和自动化。成功的设备清除提示，失败或结果待确认（操作中途断开，可能已经生效）的原因留在「消息」列，状态栏显示汇总。

## 脚本

左侧「脚本」列表新建、编辑和删除脚本；选中脚本、勾选设备后点「▶ 运行脚本」，只在自动化已就绪的设备上运行。脚本在电脑端通过 WDA 逐条执行，每行一个命令，坐标是 0–1 的相对位置，时间单位为秒。除点击、滑动、输入、启动应用等设备动作外，还支持：

- 流程控制：`重复 N`、`如果 条件 … 否则 … 结束`、`当 条件 … 结束`、`跳出`、`停止`、`失败 原因`。
- 界面元素：`点击元素 文字=登录`、`等待元素`、`等待消失`、`输入到`，条件 `存在` / `不存在`；编辑器里的「抓取节点」列出当前界面的元素和选择器。
- 图色：`比色`、`找到颜色`、`点击颜色`、`点击图片`、`等待图片`、`找到图片`，模板图片放在数据目录的 `templates`（编辑器里「打开模板目录」）。
- `随机等待`、`日志`（显示在消息列）、`截图`（保存到 `captures`）。

完整命令、示例和 EasyClick 函数对照表见 [SCRIPT_GUIDE.md](SCRIPT_GUIDE.md)。运行次数为 0 时一直循环，直到手动停止。同一台手机同一时间只运行一个脚本，最多 32 台同时运行；「脚本」「消息」列显示正在执行的脚本和步骤，出错时该设备停止并在「消息」列显示第几步失败。程序异常退出时，运行中的脚本记为「待确认」，不会自动重跑。EasyClick 等其他工具的 JS 脚本不能直接运行，需要按对照表改写。

**暂停与继续**：「‖ 暂停脚本」让脚本在当前这一步执行完后停住，「消息」列显示「已暂停 · 第几步」，设备仍算作在运行脚本（不会被其他脚本或定时任务占用），但让出「最多 32 台同时运行」的名额，排队的设备可以先跑；「▷ 继续脚本」从下一步接着执行。暂停中仍可「■ 停止脚本」，关闭中控时同样会停止。集控投屏的「暂停脚本」「继续脚本」和开放接口的 `pauseScript`、`continueScript` 效果相同。

## 定时任务

按本机时间对全部设备、某个分组或指定设备运行脚本，支持「每天定时（可选星期）」和「每隔 N 分钟」。只在中控运行期间生效，关闭期间错过的任务不补跑；每天模式到点后 10 分钟内仍会触发。到点时目标设备正在运行其他脚本（包括暂停中的脚本），会在那个脚本结束后自动补跑（每天模式限到点后 10 分钟内，间隔模式限一个间隔内）。被定时任务使用的脚本和分组不能删除。

## AI 助手

选择一台已启动自动化的手机，用一句话描述任务，AI 会看截图、逐步操作，直到调用结束或达到最多轮数。默认模型 `claude-opus-5-5`，已开启服务端拒答回退（`server-side-fallback-2026-07-01`）。API 密钥可在设置里填写（Windows 按当前用户 DPAPI 加密保存在 `settings.json`；macOS 保存在数据目录的 `agent-key` 文件，只有当前用户可读），也可用环境变量 `ANTHROPIC_API_KEY` 或 `ant auth login`。截图会发送给模型服务，按 token 计费；结果区显示本次输入、输出 token 数。

AI 不会主动输入密码、付款、发送消息或删除数据，遇到登录、验证码等情况会停下说明原因。

## 无线中心

对 USB 已信任的手机开启「Wi-Fi 连接」后，拔掉数据线、与电脑在同一局域网时仍可被识别（连接列显示 Wi-Fi），自动化与投屏走无线。Windows 需要安装 Bonjour，Apple 设备服务才能发现无线手机；无线中心会检查并提示。目前支持 iOS 16 及以下的无线控制，iOS 17 及以上需要额外的隧道服务，暂不支持。

## 集控投屏

从设备页工具栏「▣ 集控投屏」打开，与中控共用设备、任务队列和自动化通道；关闭投屏窗口不会停止它们。

- **设备墙**：每台设备一个小屏幕，点击设为主控。右键菜单：设为主控、返回主屏、锁屏、解锁、保存截图。Ctrl+滚轮缩放小屏幕。小屏幕下方的信息框按回车即发送到这一台。
- **主控画面**：点击、拖动即点按和滑动，「点击方式」可选单击、双击、长按 1 秒。画面有焦点时：回车或空格点击中心，方向键上下左右滑动，Home 键回主屏，退格键返回；按住不放只算一次，不会连发。
- **同步**：勾选「同步到全部选中设备」后，主控画面和右侧按钮的操作发给全部勾选的设备，自动跳过控制未就绪的设备。
- **右侧按钮**：Home、返回、多任务、锁屏、解锁、音量加减、四向滑动、输入文字（Ctrl+回车）、写入剪贴板、打开链接（回车）、启动或关闭应用、安装已签名应用、WDA 通道。
- **截图**：「保存主控截图」「保存选中截图」或小屏幕右键「保存截图…」，选择文件夹后保存为 `设备名_年月日-时分秒.png`，同名时加序号，不覆盖已有文件。优先保存设备的原始截图（Windows 先 USB 再 WDA，macOS 用 WDA）；都失败时保存窗口里正在显示的预览画面（约 30% 尺寸，文件名末尾带 `_preview`，不能用来截取找图模板），状态栏会注明。

Mac 上选择主控、缩放、输入框和快捷键的少数差异见 [MAC_GUIDE.md](MAC_GUIDE.md)。

### 脚本录制

1. 选好主控（需要多台一起做时勾选同步），点「● 开始录制」。
2. 在主控画面上点击、拖动，或使用右侧按钮和上面的快捷键。只有在主控（同步时没有主控则为第一台目标）上执行成功的操作才写入脚本，失败或结果待确认的不写，等待时间仍按你操作的时刻计算；小屏幕上的发送、Home 和右键菜单只作用于那一台，不录入；安装应用不能写进脚本。
3. 点「■ 停止录制」，等最后几个操作执行完（最多 10 秒）后弹出「保存录制的脚本」：可以修改名称、运行次数和每一行，「检查语法」后「保存为脚本」。保存的脚本与中控设备页的「运行脚本」和定时任务是同一份。取消后可点「保存录制」重新打开；未保存就开始新的录制、或关闭投屏窗口时，会先询问是否保存。
4. 「运行脚本」：选择脚本后点「运行到目标设备」，在主控（勾选同步时为全部选中设备）上运行；「停止脚本」「暂停脚本」「继续脚本」作用于同样的目标设备。进度见中控设备页的「脚本」「消息」列。录制中不能运行脚本。

录制生成的脚本：

- 每个操作一行，坐标为 0–1 相对位置，最多三位小数，始终用点号小数，不受系统区域设置影响。预设滑动写成 `上滑`、`下滑`、`左滑`、`右滑`、`返回`，其余写成 `滑动 x1 y1 x2 y2 秒`；长按写成 `长按 x y 秒`。
- 两个操作之间插入 `等待 秒`：取两次提交的间隔，减去上一步滑动或长按本身的时长；10 秒以内保留一位小数，之后取整，最少 0.05 秒、最多 3600 秒。开始录制到第一个操作、最后一个操作到停止的时间不写入。
- 「空闲等待上限」选 3、10 或 30 秒时，超过上限的等待按上限写入，用来去掉录制时的停顿。
- 一行只能放一个命令，文字里的换行会改成空格，并在上一行加注释说明。
- 脚本最多 2000 步（等待也算一步）、50000 个字符；达到上限时自动停止录制，最后一个操作不录入。

与 EasyClick 投屏相比，本程序只通过 WDA 控制手机，没有代理 IPA 和蓝牙、OTG、USB HID 硬件，因此暂不提供：上传图片或视频到相册、读取手机剪贴板到电脑、识别屏幕文字、HID 会话与快捷键，以及重启隧道。投屏窗口里也没有闪断 USB、重启设备和旋转屏幕的按钮：重置 USB 在中控设备页，重启在「设备详情 → 电源」或「更多 ▾」，旋转屏幕可通过开放接口 `setOrientation`。

## 开放接口

「设置 → 开放接口」可以开启兼容 EasyClick 企业版开放接口的 HTTP 服务（默认端口 8019，默认只允许本机访问），已有的 Python、易语言等对接代码改成联信中控的地址即可控制设备：设备列表、脚本启停与暂停、自动化启停、电量、开发者镜像、点按滑动输入、应用安装卸载、重启、锁屏状态与旋转、截图、抓取节点和手机文件。底部状态栏的「接口」显示服务状态；端口被占用（例如本机也在运行 EasyClick 中控）时改用其他端口。允许局域网访问时所有请求都要带设置页里的访问令牌。

文件推送与拉取（`fsyncPullPush`）在电脑一侧只能读写数据目录下的 `transfer` 文件夹，设置页会显示它的完整路径；接口不能读写电脑上的其他位置。接口清单、坐标约定、安全规则和不支持的接口见 [OPEN_API.md](OPEN_API.md)。

## 数据与设置

数据目录默认是 Windows 的 `%LOCALAPPDATA%\LianxinFleet`、macOS 的 `~/Library/Application Support/LianxinFleet.Mac/`，可用 `FLEET_DATA_DIR` 覆盖。其中有：

- `fleet.sqlite`（设备、脚本、运行记录、定时任务）、`settings.json`、`wda-runner.txt`；
- 应用批准目录 `apps`（可用 `FLEET_APP_DIR` 覆盖），安装只接受其中的 `.ipa` / `.app`；
- 脚本用的模板图片 `templates` 和截图 `captures`；
- 开放接口的文件中转目录 `transfer`（第一次推送或拉取时创建）；
- macOS 版另有 `agent-key`、`openapi-token` 两个只有当前用户可读的密钥文件。

旧数据库首次打开时自动补充新列和新表，不改动已有数据。
