# 脚本说明

联信中控的脚本由电脑端通过 WDA 逐条执行，不在手机上运行，也不使用 JavaScript。本文是完整的命令参考；中控里的脚本编辑器下方有速查，点「检查语法」可以在保存前找出错误行。

## 基本规则

- 每行一条命令，`#` 或 `//` 开头的行是注释，空行忽略。命令和参数之间用空格分隔。
- 坐标是 0–1 的相对位置：左上角 `0 0`，右下角 `1 1`，屏幕正中 `0.5 0.5`。同一脚本在不同尺寸的 iPhone 上点到相同的相对位置。
- 时间单位是秒，可以写小数，例如 `等待 0.5`。
- 每条命令都有英文写法（见各节表格），中英文可以混写。
- 上限：脚本最多 50000 个字符、2000 条命令（含块的开头和「结束」），块最多嵌套 8 层。
- 脚本的「运行次数」决定整段脚本重复几轮，0 表示一直循环直到手动停止。

## 流程控制

`重复`、`如果`、`当` 开始一个块，块必须以 `结束` 收尾；块里可以再写块。缩进只为好看，不影响执行。

| 命令 | 英文 | 说明 |
| --- | --- | --- |
| `重复 N` … `结束` | `repeat` … `end` | 执行 N 次（1–100000） |
| `如果 条件` … [`否则` …] `结束` | `if` … [`else` …] `end` | 条件成立执行前一段，否则执行 `否则` 后的一段 |
| `当 条件` … `结束` | `while` … `end` | 条件成立就反复执行；每次进入最多 10000 轮，超过以失败结束，防止无限查询手机 |
| `跳出` | `break` | 离开最近的一层 `重复` 或 `当` |
| `停止` | `stop` | 整个脚本正常结束（包括剩下的轮数） |
| `失败 [原因]` | `fail` | 脚本以失败结束，「消息」列显示原因和行号 |

```text
# 最多刷 50 个视频，出现「直播」就跳过，看到「已到底」就结束
重复 50
    如果 存在 包含=已到底
        停止
    结束
    如果 存在 文字=直播
        上滑
    否则
        随机等待 3 8
        上滑
    结束
结束
```

语法错误会指出行号，例如「第 2 行的「重复」缺少对应的「结束」」「第 5 行：「否则」前面没有对应的「如果」」「第 3 行：「跳出」只能写在「重复」或「当」循环里」。

## 条件

条件用在 `如果` 和 `当` 后面。每个条件都会实时查询手机（查元素或截一张图），前面加 `非`（`not`）表示取反，可以连写多个（偶数个等于不取反）。

| 条件 | 英文 | 成立时机 |
| --- | --- | --- |
| `存在 选择器` | `exists` | 当前界面有匹配的元素 |
| `不存在 选择器` | `notexists` | 没有匹配的元素 |
| `比色 x y #RRGGBB [容差]` | `color` | 该点颜色与给定颜色每个通道相差不超过容差 |
| `找到颜色 #RRGGBB [容差] [区域 x1 y1 x2 y2]` | `hascolor` | 区域内有符合的颜色 |
| `找到图片 名称 [相似度]` | `hasimage` | 屏幕上找到模板图片 |

## 界面元素（节点）

元素命令通过 WDA 读取 iOS 的无障碍元素树，不依赖坐标，适合按钮位置会变化的界面。

| 选择器 | 匹配 | WDA 定位方式 |
| --- | --- | --- |
| `文字=登录` | label、name 或 value 等于「登录」 | predicate string |
| `包含=登录` | label、name 或 value 包含「登录」 | predicate string |
| `id=loginButton` | 无障碍标识（accessibility id） | accessibility id |
| `类型=Button` | 元素类型，可写 `Button` 或 `XCUIElementTypeButton` | class name |
| `xpath=//XCUIElementTypeButton[@name='OK']` | XPath，较慢 | xpath |
| `谓词="label BEGINSWITH '设'"` | 原样使用的 NSPredicate | predicate string |

- 值里有空格时用英文双引号括起来：`文字="立即 登录"`；引号内的 `\"` 和 `\\` 表示双引号和反斜杠。
- `文字=`、`包含=` 的内容会按 NSPredicate 规则转义后放进单引号，任何字符都按字面匹配。`谓词=` 和 `xpath=` 原样交给 WDA，写错时脚本在该行失败并显示 WDA 的错误。
- 元素树里也包含列表中尚未滚动到屏幕上的元素；只想要可见元素时用 `谓词="label == '登录' AND visible == 1"`。

| 命令 | 英文 | 说明 |
| --- | --- | --- |
| `点击元素 选择器` | `tapelement` | 立即查找并点击第一个匹配的元素，找不到以失败结束 |
| `等待元素 选择器 [超时秒]` | `waitelement` | 每 0.5 秒查一次，直到出现；默认 10 秒，超时失败。某次查询失败（例如 WDA 短暂无响应）会继续查，超时时若最后一次仍是查询失败，报告那次的错误 |
| `等待消失 选择器 [超时秒]` | `waitgone` | 直到元素消失，例如加载提示 |
| `输入到 选择器 文字` | `inputto` | 点中该输入框并输入文字 |

`点击元素` 不会等待，界面切换后先用 `等待元素`：

```text
启动 com.apple.Preferences
等待元素 文字=通用 5
点击元素 文字=通用
等待元素 文字=关于本机
```

**抓取节点**：在中控的脚本编辑器里选择一台已启动自动化的手机，点「抓取节点」，列出当前界面的可见元素和建议的选择器；双击一行会在光标处插入 `点击元素 选择器`。建议的选择器按整个界面树核对：优先用只匹配这一个元素的 id 或文字；文字太长（超过 500 字）或含换行时改用 `包含=` 加其中一段；整个界面里还有别的元素也符合时，行尾标「不唯一，会点第一个」，请换一个选择器或改用 `xpath=`。界面树在后台整理，关闭编辑器会取消正在进行的抓取。

## 图色（找色与找图）

颜色和图片命令会截一张屏（PNG），在电脑上计算，再把命中位置换算成相对坐标点按。

- 颜色写成 `#RRGGBB` 或 `0xRRGGBB`。容差是 R、G、B 每个通道允许的最大差值（0–255），默认 16，0 表示完全相同。
- 区域写成 `区域 x1 y1 x2 y2`（`region`），是 0–1 的相对位置，默认全屏；找色从上到下、从左到右取第一个符合的点。
- 模板图片放在数据目录的 `templates` 文件夹（编辑器里的「打开模板目录」），脚本里写文件名、不带 `.png`。名称只能包含文字、数字、下划线和短横线。
- 相似度 0.5–1，默认 0.9。匹配在灰度图上做归一化相关（与 OpenCV `TM_CCOEFF_NORMED` 相同），整体变亮变暗不影响结果；透明部分按原色参与比较。
- 模板要从同一分辨率机型的截图中截取：先用 `截图` 保存整屏，在看图软件里裁出按钮另存为 PNG。不同分辨率的机型各准备一份模板。
- 找图分两步：先把模板缩成约 8×8 的方块均值，与截图在每一个像素位置开始的方块均值比较（与目标的对齐位置无关，精确截取的模板在原位置的粗搜得分就是满分），再从得分最高的若干位置在原图上逐点爬坡精确比对。1170×2532 截图上找 96×96 的模板约 50–80 毫秒，400×20、23×600 这样的细长模板也在 0.1 秒内；750×1334 上找 64×64 约 20 毫秒。几十台手机同时找图时排队计算，同时进行的不超过处理器核数的一半。

| 命令 | 英文 | 说明 |
| --- | --- | --- |
| `点击颜色 #RRGGBB [容差] [区域 x1 y1 x2 y2]` | `tapcolor` | 点按找到的第一个点，找不到以失败结束 |
| `点击图片 名称 [相似度]` | `tapimage` | 点按模板中心，找不到以失败结束 |
| `等待图片 名称 [超时秒] [相似度]` | `waitimage` | 每 0.5 秒截图找一次，默认 10 秒 |

```text
# 等首页出现后点签到按钮，签到成功（按钮变灰）就结束
等待图片 首页 15
重复 3
    点击图片 签到 0.85
    等待 1
    如果 比色 0.5 0.82 #C8C8C8 10
        日志 已签到
        停止
    结束
结束
失败 签到按钮没有变灰
```

支持的 PNG：灰度、RGB、调色板、灰度+透明、RGBA，位深 1–16；不支持隔行扫描 PNG 和 Xcode 压缩过的 CgBI 格式。

## 运行、暂停与结果

- 同一台手机同一时间只运行一个脚本，最多 32 台同时运行。运行中「消息」列显示第几轮、第几步（块内显示行号）或最近一条日志。
- 暂停在当前命令完成后生效，继续后从下一条命令接着执行；暂停中仍可停止，关闭中控时脚本同样会停止。暂停中的脚本让出「最多 32 台」的名额，排队的设备可以先运行；继续时重新排队取得名额。
- 出错时该设备的脚本结束，消息形如「第 3/8 步 · 点击元素 文字=登录 · 失败：屏幕上没有找到该元素。」；`失败` 命令显示「失败：原因（第 N 行）」。
- 无法确认手机是否已执行的动作（例如响应丢失）记为「待确认」。程序异常退出时，运行中的脚本记为「待确认」，不会自动重跑。

## EasyClick 函数对照

EasyClick 的 JS 脚本不能直接运行，常用函数按下表改写。EasyClick 用像素坐标，这里改成相对位置：相对 x ≈ 像素 x ÷ 截图宽度，相对 y ≈ 像素 y ÷ 截图高度。

| EasyClick | 联信脚本 |
| --- | --- |
| `clickPoint(x, y)` | `点击 x y` |
| `doubleClickPoint(x, y)` | `双击 x y` |
| `longClickPoint(x, y)`、`press(x, y, ms)` | `长按 x y [秒]` |
| `swipeToPoint(x1, y1, x2, y2, ms)` | `滑动 x1 y1 x2 y2 秒` |
| `inputText("内容")`、`typingText` | `输入 内容`，或指定输入框 `输入到 选择器 内容` |
| `openApp(bundleId)`、`appLaunch` | `启动 BundleID` |
| `stopApp(bundleId)`、`appKillByBundleId` | `关闭 BundleID` |
| `openUrl(url)` | `打开 url` |
| `home()`、`lockScreen()`、`unlockScreen()` | `主屏`、`锁屏`、`解锁` |
| `sleep(1000)` | `等待 1` |
| `sleep(random(1000, 3000))` | `随机等待 1 3` |
| `logd("…")` | `日志 …` |
| `exit()` | `停止` |
| 抛出异常 / `loge` 后退出 | `失败 原因` |
| `label("登录").getOneNodeInfo(1000).clickCenter()` | `等待元素 文字=登录 1` + `点击元素 文字=登录` |
| `text("登录")`、`name("登录")`、`value("登录")` | `文字=登录`（同时匹配三个属性） |
| `labelMatch(".*登录.*")` | `包含=登录`，复杂正则用 `谓词="label MATCHES '.*登录.*'"` |
| `id("x")`、`type("Button")`、`xpath("…")` | `id=x`、`类型=Button`、`xpath=…` |
| `if (label("x").getOneNodeInfo(0))` | `如果 存在 文字=x` |
| `lockNode()` + 节点面板 | 编辑器里的「抓取节点」 |
| `image.findImage(screen, tpl, …)` 后 `clickPoint` | `点击图片 名称 [相似度]`，判断用 `如果 找到图片 名称` |
| `image.cmpColor(img, "x\|y\|0xRRGGBB-0x101010", …)` | `比色 x y #RRGGBB 16`；多点比色写成嵌套的 `如果` |
| `image.findColor(…)` 后 `clickPoint` | `点击颜色 #RRGGBB [容差] [区域 …]` |
| `image.captureFullScreen()` + `saveTo` | `截图 [名称]` |
| `while (…) {}`、`for (…) {}` | `当 条件 … 结束`、`重复 N … 结束` |
| `setScriptPause(true)` | 中控里的暂停（在两条命令之间生效） |

暂不支持：变量与计算、函数、OCR 文字识别、多点触摸、线程与定时器、存储读写、HTTP 请求。
